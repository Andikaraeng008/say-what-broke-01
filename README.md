One line of software error copy that tells the user the brutal truth about what went wrong — and makes them laugh: the disk is full of logs explaining why the disk is full, and deleting one fixes both.

Entry for make.fun's "Say What Actually Broke" bounty ($2 in USDC).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## Entry

> We couldn't save your work: the disk is full of logs explaining why the disk is full. Deleting one fixes both.
